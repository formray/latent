# Specifications

Product and design specifications. Each file is dated and named so the
authoritative version is unambiguous.

Specs describe **what we're building and why**. Once a spec is locked, the
implementation plan in `../plans/` is the artifact that gets revised as
work proceeds — the spec stays stable as a north star.
