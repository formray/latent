## Launch Positioning

Latent should be announced as a hardware-backed alpha for Fujifilm
photographers, not as universal camera support.

Say clearly:

- Recipe library and creator work without hardware.
- Camera flows require Chromium WebUSB and a Fujifilm body in USB/PTP mode.
- Development validation has focused on X-S20 and X-M5.
- RAF Kelvin preview is a known limitation; WB shift is the reliable preview
  control today.
- The project is independent and not affiliated with Fujifilm.
