# External Reviews

Independent review prompts and outputs. Currently this is Codex review
rounds (`codex-review-prompt-rN.md` paired with `codex-review-output-rN.md`),
but the folder is the right place for any future external audit too.

The reviews surface risks, gaps, and counter-arguments before code lands.
Conclusions that turn into action items get tracked in `../plans/` or
`ROADMAP.md`; raw transcripts stay here as an audit trail.

## Index

- `r1` — Initial round, infrastructure surface
- `r2` — Schema↔translator lockstep + capability matrix
- `r3` — AmbiencePriority codec + nonlinear slots
- `r4` — WebUSB transport surface
- `r5` — Final pre-flight before Phase 1 close
