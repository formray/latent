# Plans

Phase-scoped execution plans. Each plan tracks a coherent milestone from
the roadmap with concrete tasks, file lists, and acceptance criteria.

Plans are **living documents** until the phase closes — they get revised
as discovery happens during implementation. When the phase ships, the
final plan stays as historical record.
